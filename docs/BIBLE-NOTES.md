# Notes des Bibles

La fonction initialement réservée au tag `Sainte Bible` est maintenant généralisée
à tous les ouvrages. La préparation, le préchargement limité aux parties voisines,
les téléchargements séparés et les tests sont documentés dans
[EPUB-NOTES.md](EPUB-NOTES.md).

Les Bibles Crampon et Glaire utilisent désormais des fichiers de notes par chapitre,
plus petits que les anciens regroupements par livre biblique. Les fichiers web
restent associés aux mêmes UUID ; leurs originaux sont reliés par
`ebook_download_files` et rangés dans `books/dl_ebooks` :

- Crampon : `c28adc3f-8674-4480-b83a-4a5057c49589`.
- Glaire : `98dd3a07-1fa2-4efa-a170-150752ff6d6a`.

Sacy ne possède pas de notes dans l’édition actuellement présente. Sa ponctuation
insécable et son téléchargement distinct sont néanmoins contrôlés. Les tests
bibliques existants restent présents en complément des tests de tous les ouvrages.
